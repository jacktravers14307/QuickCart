# QuickCart
QuickCart - E Commerce Platform


Overview:

QuickCart is an emerging online marketplace that connects buyers with a wide range of products, from electronics to household goods. The platform aims to compete with major e-commerce sites by offering a user-friendly experience, secure transactions, and efficient order fulfillment.

Tech Stack:

frontend: NextJS, TailwindCSS, Axios

Backend: NextResponse, NextRequest, iron-session, bcryptJS, mongoose, mongoDB
